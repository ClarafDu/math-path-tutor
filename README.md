# 循数 · 数学学习室

手机优先的高中数学学习网站。

## 当前版本 V1.1

- 绿白配色、黄色主要操作、红色错误提示。
- 3 个可拖动数学实验：对数函数变形、指数与对数互为反函数、对数不等式图解。支持鼠标、触屏、方向键和滑块。
- 11 个公开视频课程入口，按知识点筛选；另外提供国家平台免费课程入口。
- 6 个单元、30 道原创选择题：指数、对数定义、运算法则、条件检查、对数函数、读题逻辑。
- 概念卡、例题、两级提示、逐题反馈；提示后答对与无提示答对分开记录。
- 按最近作答安排的复习（1/3/7 天后到期，下一次使用时完成）。
- 纸笔错题照片、文字反思、手动复习标记。
- 当前浏览器本地存储；Markdown 导出、包含照片的 JSON 备份与恢复。
- 每周两天的学习记录；不显示虚构进度，也不将重复作答当作新题。

## 使用边界

这是固定题库与规则引导的 V1，不包含在线 AI 聊天、OCR、自动手写批改、账号或跨设备自动同步。照片不上传服务器，老师需要学生导出并分享才能查看记录。无痕模式或清理浏览器可能丢失本地记录，请定期备份。

一道选择题答对，只是一项学习证据，不代表章节已掌握或能够迁移。需结合纸笔步骤、陌生变式、延迟复测与教师判断。对数函数单元适合学校已经教到该部分时使用。不承诺考试分数。

题库为本项目原创内容，没有将学生姓名、成绩、私人补课 PDF 或第三方整本教材发布到仓库。

## 本地运行

需要 Node.js 18+（运行测试）和 Python 3（本地服务），没有 npm 运行时依赖。

```sh
npm test
npm start
```

打开 http://127.0.0.1:4173 。请通过 HTTP 服务访问，而不是直接双击 HTML 文件（浏览器模块需要 HTTP）。

## 发布到 GitHub Pages

本网站为纯静态 HTML/CSS/JavaScript，可直接从仓库默认分支的根目录发布。GitHub 仓库 Settings → Pages → Build and deployment，选择 Deploy from a branch、main、/(root)。

学习记录保存在访问域名对应的浏览器里。更换网站域名或路径来源前应导出备份。没有 API Key 或服务端环境变量。

## 内容维护

- `content.js`：课程概念、例题、题目、答案与分层提示。
- `graph.js`：按解析式绘制的交互函数图像、坐标变换和不等式求解。
- `videos.js`：公开课链接、知识点与观看前的问题。
- `core.js`：学习记录、复习规则和导出。
- `app.js`：交互与页面。
- `styles.css`：桌面与手机布局。
- `tests/core.test.js`：学习证据、复习与备份安全校验。

更改数学题目后，应人工核验数学推导，并运行测试。既有单元或题目 ID 要保持稳定，否则会影响历史记录匹配。

## 视频来源说明

视频入口依据 2026-11-01 视频原站公开搜索索引的标题及分集目录整理：一数的指数相关单集、高中数学公益课合集（BV1D1421m754）和刘新宇老师的高一同步课。网站只链接原站，不下载、不转载视频。自动访问 B 站详情页及元数据接口时返回 412，因此未宣称逐条完整播放验证；原站可能要求登录或调整选集。若分集调整，应按卡片题名核对并维护链接。

## V1.2 完整目录概念课

知识地图依据用户提供的五页《高中数学》目录逐节整理：19 章、131 节，全部可通过 `#concept/章节.节号` 深链接打开。每节包含直观引入、概念定义、公式及前提、推导依据、分步例题、易错提醒、独立检查与解释任务。章节筛选和关键词搜索支持手机访问。原有 6 个对数专项单元和 30 题学习记录保留。

- `curriculum-a.js`、`curriculum-b.js`、`curriculum-c.js`：原创概念讲解与检查题，按原目录划分。
- `curriculum.js`、`curriculum.css`：知识地图、概念课与本课自测的界面。
- `concept-diagrams.js`：24 类原生 SVG 交互实验，支持鼠标、触屏、滑条与键盘。每节注明实验演示的具体范围；同类概念可共用实验，不代表为每个概念制作独立动画。
- `tests/curriculum.test.js`：目录覆盖、深链接内容、圆锥曲线方程、差商与二项分布等检查。

原目录包含矩阵、算法、极坐标和极限等专题，目录完整性不等于现行上海课标或未来高考范围认证。讲解与题目为原创，未转载书中正文、原题或学生私人资料。OpenStax 公开概念索引作为进一步对照入口，不构成翻译或改编。单节自测反馈在当前页面展示，不写入原有 30 题的掌握比例，也不宣称单题正确即已掌握。旧 JSON 存档结构保持不变。
